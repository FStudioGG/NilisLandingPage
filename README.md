# Nili Salgados e Doces

Landing page oficial da **Nili Salgados e Doces**, desenvolvida para apresentar a marca e direcionar clientes aos canais de pedido e contato.

🌐 **Site:** https://www.nilisalgados.shop

---

## Sobre

Uma landing page simples, responsiva e focada em acesso rápido aos principais canais da Nili Salgados e Doces.

A página permite que o cliente:

- Faça pedidos pelo iFood;
- Faça pedidos pelo 99Food;
- Entre em contato pelo WhatsApp;
- Acesse o Instagram da marca.

O projeto foi desenvolvido como uma página estática e hospedado utilizando **GitHub Pages**.

## Tecnologias

- HTML5
- Tailwind CSS
- JavaScript
- Font Awesome
- Google Fonts
- Schema.org / JSON-LD para dados estruturados
- GitHub Pages
